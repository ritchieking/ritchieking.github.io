The agent era

2025–2026

On Netflix’s generative-AI task force for data, I worked on how viz engineers should build data products with the help of agents.

  • Supporting agents’ use of our internal charting library — Custom evaluations shaped agent skills published for the wider org.
  • Remote agent orchestration system based on a “brain and hands” model — Bootstrap docs let others create their own version.
  • Elevated product development using AI-coded experiments — Influenced development patterns across viz engineering
