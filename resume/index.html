Paid sharing, start to finish

2020–2026

Netflix’s paid-sharing initiative moved from an idea to test markets to a global launch. I gave each phase its own focused tool, did the early last-mile data work myself so the product never waited on pipelines, and retired each tool when its phase ended.

  • A scrollytelling explainer (2020) with diagrams that update as you read — something new at Netflix, and partners kept asking for more like it.
  • Test-market dashboards for the two competing approaches, with matching hero charts so leadership could compare them side by side and choose a winner.
  • The global launch dashboard, built in 12 weeks: a catalog of ~40 agreed metric definitions, an executive snapshot, a drill-down explorer, and annotated event timelines. Hundreds of colleagues used it, from product and marketing to legal and the executive office.
  • Patterns other teams picked up from this work: a metric index, full-screen zoomable charts, custom market groupings, and per-chart permalinks.

Growing the team

2024–2025

Designed the hiring process for data viz engineers on my team: three screens, including live coding and a chart-editing test, then a four-part panel.

  • Other teams adopted it, along with the four-week onboarding plan I wrote.
  • Mentored both of our new hires through pair programming and code review. Within two years, each was leading a flagship launch.
  • Took over roadmapping for the team’s viz portfolio.

Viz engineering for the agent era

2025–2026

On Netflix’s generative-AI task force for data, I worked out how viz engineers — and the agents working with them — should build data products now.

  • Benchmarked agents recreating ~300 charts using Netflix’s internal charting library, with an eval that pinpointed where models struggled. The findings fed the agent skills published for the wider org.
  • Built an agent orchestration system — planning agents write briefs, workstream agents build in parallel git worktrees — with docs so others could run their own.
  • Built a gallery where people and agents publish and reuse UI components.
  • Gave talks on labs-based product development: prototyping several options side by side, then refining, freezing, or killing each one.
